## 2025-05-22 - Hidden History **Discovery:** The `todos` array from `useHousehold` contains ALL tasks (active & completed), but the UI strictly filters out `isCompleted: true` items. **Opportunity:** Expose a "Completed" view to let users track achievements, restore accidentally completed tasks, and delete old history, with zero backend changes.
## 2025-05-24 - Habit Duplication **Discovery:** The `HabitCard` component lacked a "Duplicate" action despite the `useHousehold` hook exposing a flexible `addHabit` function and other lists (ToDos, Transactions) supporting duplication. **Opportunity:** Added "Duplicate Habit" to quickly clone habits with reset progress, enabling users to easily create habit variations or restart habit structures.
