## 2025-05-21 - Dashboard Spending Breakdown **Discovery:** Users have raw transaction data and a monthly budget view, but no immediate "at a glance" view of *where* their money is going this month on the dashboard. **Opportunity:** Aggregate current month transactions by category and display a "Top 3 Spending" card on the dashboard.
## 2025-05-15 - Share Shopping List **Discovery:** Users can export to CSV but cannot easily share a text list via SMS/Messaging. **Opportunity:** "Copy to Clipboard" feature for the Shopping List that formats it nicely (by category) for easy sharing.
## 2025-01-25 - Habit Calendar Visualization **Discovery:** The `Habit` schema already stores a flat array of `completedDates` (YYYY-MM-DD), but the UI only showed a streak number and a list log. **Opportunity:** Implemented a "Calendar View" in the Habit Log modal using this existing data, allowing users to visualize their consistency over time without any backend changes.
## 2024-01-24 - Budget History Gap **Discovery:** The `bucketHistory` collection was being populated on every pay period reset, but this data was completely inaccessible to the user (no UI, no context exposure). **Opportunity:** Implemented "Budget History" view by exposing this collection, allowing users to see their past performance and trends, closing a major loop in the budgeting workflow.

## 2025-05-24 - Saved View Persistance **Discovery:** The `SavedViewChips` component was conceptualized to persist filters to localStorage but was missing from the codebase. **Opportunity:** Implemented `SavedViewChips` to allow users to save and restore transaction filter combinations, improving workflow for frequent filter users.
