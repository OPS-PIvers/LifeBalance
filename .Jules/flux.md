## 2024-05-22 - [Transaction List Actions] **Squeeze:** [Inline Action Buttons] **Reflow:** [Move to Edit Modal]
**Fat Finger Trap:** Three 32px buttons (Edit, Duplicate, Delete) packed with 4px gaps on mobile. Easy to miss-tap.
**Data Density:** Takes up ~100px horizontal space, crowding the merchant name.
**Solution:** Hide inline actions on mobile. Make the entire transaction row a tappable target that opens the Edit/Details Modal, which already contains large, safe actions.
