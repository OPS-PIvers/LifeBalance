## Findings reframed / corrected during execution

- **B4 "Download my data" was ALREADY DONE on `main`.** Both the roadmap and the audit overstated
  this. `pages/Settings.tsx` → "Data Management" already exports a full-household JSON
  (`doExportJson`/`requestExport`, with windowed-history loading) plus a transactions CSV. The only
  gap is that export omits `todos`/`mealPlan`/`points` — a ~5-line follow-up, **not** a new feature.
  A duplicate "Download my data" section was drafted during the run and **rejected in review** to
  avoid two confusing export buttons.
- **CORRECTNESS-03 "voice expense never debits checking"** — reframed to **Plan 015 (investigate)**.
  `addTransaction` debits checking for every txn incl. `pending_review`, while Safe-to-Spend *also*
  subtracts `pending_review` (latent double-count). A naive "add a debit" would corrupt Safe-to-Spend.
- **`isTimeToSend` "ignores minutes"** — **not a bug.** Hour-only matching is intentional relaxed
  matching for hourly crons. The real (minor) follow-up is retry-deduplication.
- **SEC-08 / DEPS-01 protobufjs** — same root advisory, one fix (✅ Plan 003).
- **ARCH-03 = SEC-01 = DX-07** (admin UID in bundle) — one issue, handled with B2/Plan 009.
- **SEC-09 basic-ftp / DEPS-02** — dev-toolchain only (`firebase-tools`), not in the shipped app.
